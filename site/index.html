Use the strongest source your system allows.

The default adaptive backend combines complementary kernel signals and degrades explicitly. It never hides which sources were actually active.

Accuracy is part of the result.

Always interpret metrics with active_sources, lost-event counters, sample gaps, and counter resets. A fallback report is useful — and intentionally less complete.

Quick start

From process ID to evidence in seconds.

Download a prebuilt Linux archive or build with Go 1.22+. Run doctor first to see which data sources the current kernel and permissions support.

  1. 1
    Check capabilities

    Inspect eBPF, taskstats, and procfs availability.

  2. 2
    Capture intervals

    Start with the adaptive auto backend.

  3. 3
    Read quality first

    Confirm sources, gaps, lost events, and resets.

01Check your system
tsastat doctor
02Monitor a process
sudo tsastat -p 1234 --backend auto \
  --sample 10ms --interval 1s --count 10
03Save a report
sudo tsastat -p 1234 --backend auto \
  -i 1s -c 30 -o json > report.jsonl
